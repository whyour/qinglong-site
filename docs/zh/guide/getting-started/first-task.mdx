# 创建第一个任务

本教程使用一个只打印时间的 JavaScript 脚本，完成安装、初始化、运行和查看日志的流程。

## 1. 安装面板

按照 [Docker Compose 部署](./installation-guide/docker-compose)启动面板，或选择其他[安装方式](./installation-guide)。访问 `http://localhost:5700`；远程部署时使用服务器地址和实际映射端口。

首次打开时按页面提示创建管理员账号并完成初始化。已有面板直接登录即可。

## 2. 添加脚本

进入「脚本管理」，在脚本根目录新建 `hello.js`，保存以下内容：

```javascript
console.log('Hello, Qinglong!');
console.log(new Date().toISOString());
```

这个脚本不需要安装额外依赖，也不需要配置环境变量。若放入子目录，后续命令也要包含该相对路径。

## 3. 创建定时任务

进入「定时任务」并新建任务：

| 字段 | 内容 |
| --- | --- |
| 名称 | 第一个任务 |
| 命令 | `task hello.js` |
| 定时规则 | `0 9 * * *` |

该规则表示每天 09:00 执行，使用面板配置的时区。保存后确认任务已启用；本教程无需等待下一次定时触发。

## 4. 手动运行并查看日志

在任务列表运行刚创建的任务，然后打开该任务的日志。预期看到 `Hello, Qinglong!` 和一行时间。

运行请求被接受只表示任务已提交。应等待本次运行结束，再确认日志内容及执行结果；不要把上一次运行的日志当成本次结果。

若提示找不到文件，确认脚本名称、所在目录及命令中的路径一致；若无法打开页面或任务没有启动，参考[维护与故障排查](../user-guide/maintenance)。

## 5. 用 CLI 管理（可选）

按照 [CLI 使用指南](../user-guide/cli)安装并登录远程 CLI，在应用权限中授权 `crons`：

```bash
ql task list --search hello.js --json
```

从结果中取得实际任务 ID 后，再运行和查看日志。下面的 `12` 仅为示例：

```bash
ql task run 12 --json
ql task logs 12 --tail 50 --json
```

练习完成后可在面板禁用该任务，保留脚本供后续修改。继续阅读[内置 API](../user-guide/built-in-api)了解脚本如何调用面板功能。
