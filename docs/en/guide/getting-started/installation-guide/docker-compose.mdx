# Docker Compose

Install Docker and the [Compose plugin](https://docs.docker.com/compose/install/), and verify `docker compose version`. Create and enter a deployment directory:

```bash
mkdir -p qinglong
cd qinglong
```

Save the following as `compose.yaml` in this directory:

```yaml
services:
  qinglong:
    image: whyour/qinglong:latest
    container_name: qinglong
    hostname: qinglong
    restart: unless-stopped
    ports:
      - "5700:5700"
    volumes:
      - ./data:/ql/data
    environment:
      QlBaseUrl: "/"
      QlPort: "5700"
```

```bash
docker compose config
docker compose up -d
docker compose logs --tail 100 qinglong
```

Open `http://localhost:5700`; replace localhost with the server address for a remote host. Data persists in this directory’s `data` folder. See [Docker deployment](./docker) for Debian and non-root options.

Stop and restart from the same deployment directory:

```bash
docker compose stop
docker compose start
```
