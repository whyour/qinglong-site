# Podman

Install [Podman](https://podman.io/docs/installation). This example runs the container as root for Alpine crond:

```bash
mkdir -p "$PWD/ql/data"
sudo podman run -dit \
  --network bridge \
  -v "$PWD/ql/data:/ql/data" \
  -p 5700:5700 \
  -e QlBaseUrl="/" \
  -e QlPort="5700" \
  --name qinglong \
  --hostname qinglong \
  docker.io/whyour/qinglong:latest
```

`QlBaseUrl` can specify a path prefix such as `/test`. `QlPort` defaults to `5700` and must match the right side of the port mapping. Open `http://localhost:5700` to initialize the panel.

On SELinux hosts with mount permission errors, use `-v "$PWD/ql/data:/ql/data:Z"` when appropriate for your host policy. Non-root deployments should use the Debian image and verify user mapping and mount permissions.

Inspect startup logs:

```bash
sudo podman logs --tail 100 qinglong
```
